## 一、背景与根因（来自用户真机上传日志 `HL-MQXZC8` 反馈）

用户升级到 Hunter v3.5.0（AtomCode 5.1.0 内核）与启动器 `0.1.23` 后上传了日志 `HL-MQXZC8`，指出两个问题：
1. **产品已升级为基于 `AtomCode` 内核，但启动器界面（运行面板服务卡片、日志页筛选标签）以及上传的诊断日志报告（概要端口行、`docker compose ps`、容器日志分节标题 `===== opencode 容器日志 =====`）里显示的还是旧名字 `opencode`。**
   - 根因：为了兼容老版启动器，v3.5.0 的 `docker-compose.yml` 里服务名沿用了 `opencode:`，而启动器前后端和诊断报告直接把这个底层兼容 key 原样展示给了用户。
2. **偶发「解析不了上游主机名 hunter.agentpit.io（2011ms）」。**
   - 根因：启动器 `src-tauri/src/runtime/vmdns.rs` 写入虚拟机 `/etc/resolv.conf` 的 `NAMESERVERS` 把 `192.168.5.2` 放在第一顺位；在用户开启系统代理或唤醒时 `192.168.5.2` 常不响应 DNS，导致容器每次冷查询都要白白卡满 2000ms（`timeout:2`）才切到第二顺位 `223.6.6.6`。

## 二、本轮改动清单

1. **前端展示层全面正名为 `atomcode`**：
   - `src/pages/Logs.tsx`：`SERVICES` 列表中的 `'opencode'` 改为 `'atomcode'`（`['web', 'api', 'atomcode', 'llm-shim', 'postgres', 'redis']`）。
   - `src/components/ServiceTile.tsx`：当 `svc.service === 'opencode' || svc.service === 'daemon'` 时，卡片展示标签统一显示为 `'atomcode'`。
   - `src/i18n/zh-CN.ts` 与 `src/i18n/en.ts`：
     - `pull.roles` 同时保留 `atomcode`、`daemon`、`opencode` 映射为 `'对话引擎'` / `'Conversation engine'`；
     - `backup.restoreSteps`、`settings.modelOwnHint`、`feedback.attachHint` 中面向用户的 `opencode` 文案全部更新为 `atomcode`，保持中英文 key 结构 100% 对齐。
   - `src/lib/demo.ts`：`demoDiagSections`（概要端口行、`docker compose ps`）与 `demoComposeLog` 中的 `opencode` 更新为 `atomcode`。
2. **后端日志拉取与诊断报告（`compose.rs` & `feedback.rs`）正名为 `atomcode` 并保持底层兼容**：
   - `src-tauri/src/compose.rs`：
     - `display_order` 中将 `"atomcode" | "daemon" | "opencode"` 统一排在索引 `2`；
     - `compose::logs` 新增 `resolve_log_service`，当传入 `"atomcode" | "daemon" | "opencode"` 时自动映射为 `crate::config::current_engine_service()`（底层 compose 实际服务名 `"daemon"` 或 `"opencode"`）；
     - 新增 `normalize_log_line_prefix`，将输出行首的 `"opencode-1  | "` 替换为 `"atomcode-1  | "`、`"hunter-opencode-1  | "` 替换为 `"hunter-atomcode-1  | "`；
     - 新增单元测试 `日志服务映射与前缀规范化为_atomcode`。
   - `src-tauri/src/feedback.rs`：
     - 概要端口行改为 `"端口: web {} · api {} · atomcode {} · postgres {} · redis {}\n"`；
     - `docker compose ps` 格式化时将 `"opencode"` 或 `"daemon"` 映射为 `"atomcode"` 展示；
     - 容器日志收集遍历 `["api", eng, "llm-shim"]` 时，对话引擎分节 `id` 固定为 `"log-atomcode"`，`title` 固定为 `"atomcode 容器日志（最近 100 行 · content/text 已整段抹除）"`，空日志说明固定为 `"atomcode 没有日志输出"`；
     - 新增单元测试 `诊断报告统一使用_atomcode_名称而非_opencode`。
3. **内置虚拟机 DNS 顺序优化（`src-tauri/src/runtime/vmdns.rs`）**：
   - 将 `NAMESERVERS` 调整为国内高可用公共 DNS（`223.6.6.6`、`119.29.29.29`）排在第一、第二顺位，`192.168.5.2`（lima 网关）排在第三顺位兜底，并同步更新单测断言。
