## 发现的问题
### F1（P0）macOS 上自更新完全不可用
`--self-update`（从 0.1.12 起）→ 清单取自腾讯云香港（正确）→ **下载的是 `hunter-launcher_0.1.13_amd64.deb`**，然后走 osascript 提权执行 `dpkg` →
`E_NOT_IMPLEMENTED: /bin/sh: dpkg: command not found (127)`。日志：`2026-09-23 23:34:55 已下载并验签 hunter-launcher_0.1.13_amd64.deb`。
应为：mac 取 `*_universal.app.tar.gz`，验签后就地替换 `/Applications/Hunter Launcher.app`（用户可写时不需要管理员），重启自己。顺带纠正界面上那句「这台机器上的启动器是 macos 形式装的，换包要管理员权限」。

### F2（P1）删除计划里的体积数字虚高约 15 倍且重复
`--uninstall-plan` 报「工作目录 86.1 GB / 运行环境 86.1 GB」，实测 `du -sh ~/.hunter` = **5.8 GB**（虚拟机是稀疏文件：表观 20G、实占 1.7G）。两行数值完全相同，疑似同一处算错并复用；另外「不能同时删运行环境」那段警告**连续打印了两次**。

### F3（P1）重装不沿用保留下来的 key
「只删应用」保留了 `~/.hunter/app/.env`（里面有 key 与 JWT_SECRET），但 `--auto -y` 仍报 `E_KEY_INVALID: 标准输入不是终端…用 --key-file`。既然 .env 已在且刚刚被承诺「重装会直接沿用」，应先读它；GUI 路径是否预填未验。

### F4（P1）删除应用会移除定时备份任务，重装后不会自动装回
本次是手工 `--schedule install` 才恢复。应在重装完成后按 `[backup] enabled` 自动重建，或在界面上明确提示。

### F5（提示）Hunter 有新版本 v1.2.1
`--check-update` 报 v1.2.0 → v1.2.1（2026-09-22 发布，补丁级、无库变更）。`--upgrade` 这条路本轮未验。
