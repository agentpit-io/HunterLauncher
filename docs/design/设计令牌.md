# Hunter 启动器 · 设计令牌

> 所有数值来自 `plan/UI/` 下三张视觉稿的**逐像素采样**，采样脚本 [`scripts/sample-mockup.py`](../../scripts/sample-mockup.py)，
> 改令牌之前先跑一遍它对账。
> 实现在 [`src/styles/tokens.css`](../../src/styles/tokens.css)，Tailwind 的映射在 [`src/styles/index.css`](../../src/styles/index.css)。
>
> **视觉稿是 2 倍图**：图片 2360×1520 对应约 1180×760 逻辑像素，因此下表里「稿上像素」÷2 才是写进令牌的逻辑像素。
>
> 采样方法：纯色区域取**众数**（避开 JPEG 压缩噪点），文字取区域内**最亮像素**（文字抗锯齿，峰值最接近真实字色）。

## 二、字体

| | 字体 | 许可证 | 打包形式 |
|---|---|---|---|
| 中文无衬线 | **Noto Sans SC** | SIL Open Font License 1.1 | 可变字体子集 `noto-sans-sc-subset.woff2` · **199 KB** |
| 等宽 | **JetBrains Mono** | SIL Open Font License 1.1 | 可变字体子集 `jetbrains-mono-subset.woff2` · **30 KB** |

- **全部本地打包，不走 CDN** —— 启动器必须离线可用（总控规则技术栈一节）。
- 两份许可证全文随字体一起放在 [`src/assets/fonts/`](../../src/assets/fonts/)（OFL 要求随分发附带）。
  OFL 允许嵌入与再分发，也允许做子集，唯一的硬要求是不能把字体单独卖钱、要附带许可证、
  以及**不能用保留字体名（Reserved Font Name）发布修改版** —— 子集化不改名，不触发这一条。
- **为什么是子集**：Noto Sans SC 完整一档约 10 MB，三档会把 `.deb` 从 2.3 MB 撑到几十 MB。
  界面文案是有限且写死在仓库里的，子集（853 个字符，其中汉字 717 个）足够。
- **子集没覆盖到的字**（例如 Docker 报错里冒出来的生僻字）按 `--hl-font-sans` 的回落链
  走系统中文字体（PingFang SC / 微软雅黑 / Noto Sans CJK），不会变成豆腐块。
- 重新生成：`/tmp/fonttools-venv/bin/python scripts/build-fonts.py`（脚本头部有 venv 的建法）。
  产物已提交进仓库，**CI 与日常开发都不需要跑它**。

```css
--hl-font-sans: 'Noto Sans SC', 'PingFang SC', 'Microsoft YaHei', 'Noto Sans CJK SC',
  'Source Han Sans SC', 'Hiragino Sans GB', system-ui, -apple-system, sans-serif;
--hl-font-mono: 'JetBrains Mono', 'SFMono-Regular', 'Menlo', 'Consolas',
  'Noto Sans SC', 'PingFang SC', 'Microsoft YaHei', monospace;
```

等宽字体后面挂中文回落是有意的：日志里混着中文（「持仓 12 只 · 2 条异动」），
JetBrains Mono 没有汉字，得有人接住。

**所有数字一律等宽**（`.tnum` 工具类，`font-variant-numeric: tabular-nums`）——
视觉稿里的额度、端口、镜像大小、时间戳全部是等宽的，进度跳动时数字不会左右抖。

## 四、间距阶梯

4 的倍数，实测值向阶梯就近取整：

| 令牌 | 值 | 实测依据 |
|---|---|---|
| `--hl-sp-1` … `--hl-sp-4` | 4 / 8 / 12 / 16 px | — |
| `--hl-sp-3` | **12px** | 卡片之间的间隙（稿上 26px@2x） |
| `--hl-sp-5` | **20px** | 卡片内边距（稿上 38–40px@2x） |
| `--hl-sp-6` | **24px** | 侧栏左内边距（logo 左边缘 x=126，窗口左 x=80） |
| `--hl-sp-10` | **40px** | 向导底部留白（按钮底 1368 → 窗口底 1449） |
| `--hl-sp-11` | **44px** | 运行面板左右内边距（稿上 88–90px@2x） |
| `--hl-sp-12` | **48px** | 向导内容区左右内边距（稿上 96px@2x） |

向导和运行面板的左右内边距确实不一样（48 vs 44），不是测量误差 —— 两次分别在两张稿上量到同一组值。

## 八、K 线装饰的几何

十三根蜡烛的中心 x、影线上下端、实体上下端全部量自视觉稿第 1 张，
写死在 `components/CandlestickDecor.tsx` 的 `CANDLES` 数组里（单位逻辑像素，整块 226×116）。
第 10 根（下标 9）是金色的那根。蜡烛间距 18px，实体宽 9.5px，影线宽 1.5px。
